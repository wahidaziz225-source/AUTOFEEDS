2. Mulai atau perbarui aplikasi

Jika memperbarui proyek lama: hentikan server, lalu backup folder proyek terutama database dan storage. Salin source baru tanpa menghapus data tersebut.
  1. Ekstrak paket AUTOFEEDS-fase8.zip dan buka folder source di dalamnya.
  2. Pastikan Node.js 22+ dan Python 3.10+ terpasang. Aktifkan opsi Python pada PATH saat memasang Python.
  3. Klik dua kali 1-INSTAL-WINDOWS.bat. Tunggu sampai instalasi dasar selesai. Langkah ini memerlukan internet untuk dependensi.
  4. Klik dua kali 2-MULAI-WINDOWS.bat.
  5. Tunggu tulisan Ready, lalu buka http://localhost:3000.
  6. Biarkan jendela terminal terbuka selama memakai aplikasi. Tekan Ctrl+C untuk berhenti.

Pada pemakaian berikutnya cukup jalankan file nomor 2. Sesudah menyalin pembaruan source, jalankan ulang server dan muat ulang halaman agar perubahan terlihat.

Alternatif menggunakan terminal

Buka terminal pada folder proyek, kemudian jalankan:

npm ci
python -m pip install -r requirements.txt
npm run dev

File BAT disiapkan sebagai pendamping Windows, tetapi belum dijalankan langsung pada Windows dalam pengujian ini. Aplikasi/ekspor diuji pada Linux dan Chromium. Jangan unggah folder database/storage ke hosting hanya untuk menjalankan aplikasi lokal.

3. Alur pembuatan poster

Siapkan brand → Upload foto → Buat variasi → Edit → Unduh

A. Brand Kit

Buka Brand Kit → Brand Kit baru. Isi nama, warna utama/sekunder/aksen, font dan footer. Upload logo jika ada, pilih default bila diperlukan, lalu Simpan Brand Kit.

Kit tetap bisa dipakai tanpa logo. Identitas pada hasil lama disimpan sebagai snapshot, sehingga tidak berubah saat kit diperbarui.

B. Upload foto

Buka Image Upload, pilih atau seret foto, beri nama/kategori, lalu Simpan semua. Gunakan nama produk yang mudah dikenali.

Foto asli tetap disimpan. Logo yang diunggah juga tersedia sebagai gambar; pastikan memilih foto produk yang benar saat membuat poster.

C. Pengolahan foto (opsional)

Buka Product Image Studio. Atur cahaya, kontras, atau ketajaman, lalu Buat hasil foto. Hasil disimpan sebagai varian baru.

Untuk mengganti background foto biasa, pasang model penghapus background dan aktifkan AI. PNG yang sudah transparan dapat dikomposisikan tanpa model tersebut.

D. Promo Composer

Pilih 1–6 produk, jenis promo dan harga sesuai label. Pada Harga spesial, harga promo diisi langsung; harga coret opsional.

Pilih foto asli/hasil olahan, Brand Kit, konsep, ukuran dan jumlah 4, 5 atau 6 variasi. Klik tombol pembuatan, tunggu semua hasil selesai, lalu bandingkan thumbnail.

Simpan desain pilihan memberi tanda favorit; semua hasil yang berhasil dibuat sudah ada dalam riwayat. Buat ulang atau Buat variasi tambahan memakai data tersimpan dari hasil terpilih, bukan perubahan formulir yang belum dikirim.

Untuk ukuran khusus pada Composer: pilih Ukuran → Ukuran khusus, isi Lebar/Tinggi, lalu buat poster. Untuk awal, gunakan preset besar; canvas kecil dengan banyak produk dapat membuat teks mengecil.

4. Mengedit dan mengunduh

  1. Pada hasil Composer, klik Edit desain (salinan). JPG asal tidak ditimpa.
  2. Klik elemen pada canvas atau pilih dari daftar Layer. Seret untuk memindah, pegangan kotak untuk resize, dan bulatan untuk rotasi.
  3. Ubah teks, font, warna, opacity, posisi, atau urutan lewat panel Properti layer. Layer terkunci harus dibuka kuncinya terlebih dahulu.
  4. Untuk ukuran lain, isi Lebar khusus dan Tinggi khusus, lalu Terapkan ukuran. Periksa kembali susunannya.
  5. Klik Simpan atau Ctrl+S. Undo/redo tersedia selama sesi. Salin dokumen dapat dipakai untuk menyimpan versi baru.
  6. Pilih format unduhan yang dibutuhkan:
FormatCara dan hasil
JPGPilih kualitas 85%, 95% atau 100%, lalu Unduh JPG. Area transparan diratakan menjadi putih.
PNGKlik Unduh PNG. Jika ingin transparansi, sembunyikan layer Background terlebih dahulu. PNG tidak otomatis menghapus background yang masih terlihat.
SVGKlik Unduh SVG untuk elemen vektor dan gambar tertanam. Font tidak ikut tertanam; tampilan di aplikasi lain dapat memakai fallback.
Mengunduh tidak otomatis menyimpan perubahan. Harga promo, harga coret dan label diskon merupakan layer mandiri; ubah masing-masing bila diperlukan.

Poster baru menyimpan PNG dari canvas asli. PNG untuk poster lama yang hanya mempunyai JPG dibuat dari JPG tersimpan; konversi tersebut tidak mengembalikan detail yang sudah hilang.

5. Caption dan template

Content Studio

Pilih foto, gunakan hasil analisis atau isi fakta manual. Pilih brand, bahasa Indonesia/English, gaya dan jenis konten seperti caption, CTA, copywriting atau edukasi. Tulis fakta/harga yang benar pada Info tambahan, misalnya Harga Rp25.000, lalu klik Buat konten.

Ollama dan model teks harus sudah terpasang dan berjalan. Periksa hasil, lalu simpan ke Content Library, salin, atau unduh TXT. Filter harga tidak memverifikasi otomatis semua klaim produk.

Template brand

Terapkan Brand Kit pada dokumen editor dan Simpan. Di Brand Kit, pilih dokumen serta nama template, kemudian Simpan template untuk brand ini. Gunakan template membuat dokumen baru dengan salinan asetnya sendiri.

Pemasangan AI foto opsional

Dari folder proyek, gunakan Python yang sama dengan aplikasi:

python -m pip install -r requirements-ai.txt
python scripts/setup_background_model.py

Setelah selesai, muat ulang halaman Product Image Studio. Model foto tidak diperlukan untuk membuat poster, mengedit layer, atau pengaturan cahaya dasar.

7. Status pengujian dan penerapan

48 tes otomatis (27 Node + 21 Python), TypeScript, lint, build, uji API dan browser lolos. Ekspor diuji pada ukuran preset dan custom, PNG transparan, JPG putih, kualitas JPG, serta data lama. Regresi Fase 4–7 tetap lolos.

Pengujian browser memakai Chromium Linux dengan viewport desktop/HP dan data DEMO. Windows/GPU AMD dan HP fisik pengguna belum diuji langsung. Regresi model foto memakai model CPU nyata; kualitas model teks nyata belum diuji, karena pengujian alur Ollama menggunakan server fixture.

Paket source lengkap mencakup Fase 3–8. Perubahan belum dikirim ke GitHub dan tidak dipublikasikan otomatis.

Backup database serta seluruh storage ketika aplikasi berhenti. Laporan teknis: docs/FASE-8-EKSPOR-DAN-VALIDASI.md di paket aplikasi.
